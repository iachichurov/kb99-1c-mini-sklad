# Мини-Склад

Учебный проект на платформе **1С:Предприятие 8**, подготовленный в рамках практики KB99.

## Что реализовано

- Справочники `Товары` и `Контрагенты`.
- Документы `Поступление` и `Реализация` с формами ввода.
- Подсистема `МиниСклад`.

**Регистров и движений нет.** Складские остатки не рассчитываются. Проект демонстрирует начальную структуру конфигурации.

## Состав репозитория

- `Configuration.xml` — корневой файл конфигурации.
- `ConfigDumpInfo.xml` — служебная информация о файловой выгрузке.
- `Catalogs/` — справочники.
- `Documents/` — документы и их формы.
- `Subsystems/` и `Languages/` — подсистема и язык конфигурации.
- `README.md` — описание проекта и порядок запуска.
- `.gitignore` — исключения для рабочей базы, резервных копий и временных файлов.

В репозитории хранится XML-выгрузка конфигурации без данных информационной базы. Рабочая база `InfoBase/` и бинарные выгрузки `*.cf` остаются локально и исключены из Git.

## Как запустить

В конфигурации установлен режим совместимости **8.5.1**. Потребуется версия платформы 1С:Предприятие, которая поддерживает этот режим и формат выгрузки.

1. Скачайте репозиторий или клонируйте его через Git.
2. В окне запуска 1С добавьте **новую пустую информационную базу** без конфигурации.
3. Откройте эту базу в режиме **Конфигуратор**.
4. Выберите **Конфигурация → Открыть конфигурацию**, затем **Конфигурация → Загрузить конфигурацию из файлов**. Укажите формат XML и корневую папку репозитория, содержащую `Configuration.xml` и каталоги объектов.
5. Выполните **Конфигурация → Обновить конфигурацию базы данных (F7)** и подтвердите изменения.
6. Запустите режим **1С:Предприятие**. Справочники и документы доступны для заполнения; тестовые данные вводятся отдельно.

## Обновление выгрузки

После изменения конфигурации выполните **Конфигурация → Выгрузить конфигурацию в файлы**. Выберите формат XML, иерархическую структуру и корневую папку репозитория. Добавьте изменённые XML-файлы и файлы модулей, если они появились, в новый коммит. Рабочая база остаётся в папке `InfoBase/` локально.
