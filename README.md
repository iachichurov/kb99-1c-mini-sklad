# Мини-Склад

Учебный проект на платформе **1С:Предприятие 8**, подготовленный в рамках практики KB99.

## Что реализовано

- Справочники для хранения данных.
- Документы для ввода операций.

**Регистров и движений нет.** Складские остатки не рассчитываются. Проект демонстрирует начальную структуру конфигурации.

## Состав репозитория

- `1Cv8.cf` — выгрузка конфигурации 1С.
- `README.md` — описание проекта и порядок запуска.
- `.gitignore` — исключения для рабочей базы, резервных копий и временных файлов.

Папка `InfoBase/` содержит локальную рабочую базу и не включается в Git. Файл `.cf` содержит конфигурацию, но не данные информационной базы.

## Как запустить

Потребуется установленная платформа 1С:Предприятие 8 версии, совместимой с файлом конфигурации.

1. Скачайте репозиторий или клонируйте его через Git.
2. В окне запуска 1С добавьте **новую пустую информационную базу** без конфигурации.
3. Откройте эту базу в режиме **Конфигуратор**.
4. Выберите **Конфигурация → Открыть конфигурацию**, затем **Конфигурация → Загрузить конфигурацию из файла** и укажите `1Cv8.cf`.
5. Выполните **Конфигурация → Обновить конфигурацию базы данных (F7)** и подтвердите изменения.
6. Запустите режим **1С:Предприятие**. Справочники и документы доступны для заполнения; данные из локальной рабочей базы в выгрузку `.cf` не входят.

## Обновление выгрузки

После изменения конфигурации сохраните её через **Конфигурация → Сохранить конфигурацию в файл**, замените `1Cv8.cf` в репозитории и создайте новый коммит. Рабочая база остаётся в папке `InfoBase/` локально.
